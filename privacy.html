FRIDAY

Política de privacidad

Última actualización: 22 de octubre de 2026.

Esta política explica cómo el proyecto personal FRIDAY trata los datos cuando se utilizan sus páginas e integraciones. FRIDAY utiliza n8n para coordinar automatizaciones e integraciones con servicios digitales.

1. Responsable del proyecto

FRIDAY es un proyecto personal de automatización. Para consultas sobre privacidad o el tratamiento de datos, utiliza la siguiente dirección de contacto:

Correo de contacto: fridayassistant@gmail.com

2. Datos que pueden tratarse

Dependiendo de las integraciones que el propietario active, FRIDAY puede procesar datos necesarios para ejecutar las operaciones solicitadas, como títulos y fechas de tareas, detalles de eventos del calendario y otra información proporcionada expresamente a través de las integraciones.

Si se habilitan flujos relacionados con el correo electrónico, estos podrán procesar los datos de los mensajes necesarios para realizar la operación solicitada.

3. Uso de los datos de Google

El uso y la transferencia a otras aplicaciones de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios API de Google, incluidos sus requisitos de uso limitado (Limited Use).

Los datos obtenidos mediante las API de Google se utilizan para ejecutar las funciones solicitadas por el propietario. No se venden los datos de Google ni se utilizan para publicidad personalizada.

4. Almacenamiento y seguridad

Las operaciones se coordinan mediante n8n. Según la integración, la configuración de los flujos y los ajustes de ejecución, los datos pueden procesarse temporalmente o conservarse en los sistemas que intervienen en la automatización.

Se aplicarán medidas razonables para proteger las credenciales y limitar el acceso a los sistemas. Ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

5. Proveedores externos

El funcionamiento del proyecto puede implicar servicios de terceros, como Google, n8n y GitHub Pages, cada uno sujeto a sus propias condiciones y políticas de privacidad. Estos proveedores pueden tratar los datos técnicos necesarios para prestar sus servicios.

6. Conservación y eliminación

La conservación de los datos depende de los servicios utilizados y de la configuración de sus registros, ejecuciones y copias de seguridad. Los datos se eliminarán cuando dejen de ser necesarios, teniendo en cuenta las limitaciones técnicas y las obligaciones legales aplicables.

El acceso a Google puede revocarse desde la configuración de seguridad de la cuenta de Google. Revocar el acceso no elimina automáticamente los datos que pudieran haberse conservado previamente en otros sistemas.

7. Derechos y consultas

Para consultar, corregir o solicitar la eliminación de datos personales tratados por el responsable del proyecto, escribe a la dirección de contacto indicada anteriormente. También puedes presentar una reclamación ante la autoridad de protección de datos competente.

8. Cambios en esta política

Esta política podrá actualizarse cuando cambien las funciones, las integraciones o las prácticas de tratamiento de datos. La versión vigente estará publicada en esta página.
